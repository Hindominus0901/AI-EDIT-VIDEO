# Font C cho renderer 1.5

Manrope.ttf: static Bold 700, family trình duyệt `Manrope Editorial`.
Playfair.ttf: static Italic 650, family trình duyệt `Playfair Editorial`.
Renderer nạp và chờ FontFace hoàn tất, báo lỗi nếu thiếu; không âm thầm dùng font hệ thống.
Hai giấy phép OFL kèm thư mục. Dùng `premiumSet: "editorial-c"`; không đổi mặc định mọi khách hàng.
